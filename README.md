## Karina Love — многостраничный сайт ко Дню всех влюблённых

Проект — это романтический многостраничный сайт для Карины, созданный на React + Vite.

### Как запустить сайт локально

1. **Установить зависимости**
   ```bash
   npm install
   ```

2. **Запустить дев-сервер**
   ```bash
   npm run dev
   ```

3. Открой URL из консоли (обычно `http://localhost:5173`) в браузере.

---

### Как запушить проект на GitHub (пошаговая инструкция)

#### 1. Создай репозиторий на GitHub

- Зайди на GitHub и нажми **New** (создать новый репозиторий).
- Введи название, например `karina-love`.
- Не создавай README, `.gitignore` и т.п. (оставь пустым), чтобы избежать конфликтов.
- Нажми **Create repository**.

#### 2. Инициализируй git в папке проекта

В терминале, находясь в папке проекта (`/home/dmitri/karinaLove`):

```bash
git init
git add .
git commit -m "Первый коммит: сайт для Карины"
```

#### 3. Привяжи локальный проект к удалённому репозиторию

Скопируй адрес репозитория с GitHub (например `https://github.com/ТВОЙ_ЛОГИН/karina-love.git`)  
и выполни:

```bash
git remote add origin https://github.com/ТВОЙ_ЛОГИН/karina-love.git
```

Если уже есть удалённый `origin` и нужно заменить:

```bash
git remote set-url origin https://github.com/ТВОЙ_ЛОГИН/karina-love.git
```

#### 4. Запушь код на GitHub

Чаще всего главная ветка называется `main`:

```bash
git branch -M main
git push -u origin main
```

После этого код проекта с сайтом для Карины будет на GitHub.

---

### (Необязательно) Как выложить сайт через GitHub Pages

1. Собери продакшн-версию:
   ```bash
   npm run build
   ```
2. Зайди в настройки репозитория на GitHub: **Settings → Pages**.
3. В разделе **Source** выбери ветку `gh-pages` или включи публикацию из `Actions` (подход зависит от настроек GitHub).
4. Можно подключить готовый workflow для Vite (через **Actions → New workflow**), чтобы деплой происходил автоматически после пуша.

Через несколько минут сайт для Карины станет доступен по адресу GitHub Pages.
